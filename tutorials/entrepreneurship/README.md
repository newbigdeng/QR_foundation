# Entrepreneurship：一人量化公司的经营课

技术之外，一人公司还要处理主体、账户、数据许可、资金杠杆、会计税务与业绩归因。共 3 本，全部可运行、0 error / 0 stderr。

| 文件 | 主题 | 你会得到 |
|---|---|---|
| `01_一人量化公司主体合规与数据许可.ipynb` | 主体形式、券商开户/权限、数据供应商许可、留痕、外包保密、启动/年度成本 | 一张公司启动与合规清单 |
| `02_资金杠杆与公司级风控.ipynb` | 自有资金/杠杆/保证金/强平/回撤/破产概率、资金分配、kill switch、压力测试 | 杠杆与资金分配表 |
| `03_会计税务与业绩归因.ipynb` | 三本账、显性/隐性费用、税口径、按策略/品种归因、月度报表 | 一套可对账的账本与归因表 |

## 怎么用

在 `tutorials/` 目录下启动 Jupyter：

```bash
cd tutorials
jupyter lab
```

打开 `entrepreneurship/` 下对应 notebook。代码只用 `numpy/pandas/matplotlib`，数据为教学示例。

## 重要声明

- 本目录是**教学材料，不构成法律、税务、投资、合规意见**。
- 主体形式、税率、券商费用、数据许可条款、交易所规则都会变化；实际操作前请咨询律师/税务师/券商/数据供应商。
- 所有数字均为示例，不能直接作为经营预算或合规依据。
