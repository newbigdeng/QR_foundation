# Advanced：QR 进阶与实盘工程

主线 45 本之后，补足“独立 QR + 一人公司”最缺的工程闭环。共 6 本，全部可运行、0 error / 0 stderr。

| 文件 | 主题 | 你会得到 |
|---|---|---|
| `01_事件驱动回测与撮合.ipynb` | 订单/成交/持仓/现金逐笔账；限价/市价/撤单/部分成交/拒单；手续费/滑点/冲击/保证金；与 WT-plus 回放对账 | 一个最小事件驱动回测器 + 一笔完整交易对账 |
| `02_数据工程与PIT.ipynb` | 供应商数据字典、PIT/修订、复权、期货换月/夜盘归属、存活偏差、停牌/涨跌停、质量断言、版本快照 | 可复现的 PIT 面板 + 质量报告 |
| `03_执行算法与微观结构.ipynb` | 订单簿/价差/深度/队列；TWAP/VWAP/POV；冲击成本、成交率、滑点、容量 | 执行算法对比 + 执行对账表 |
| `04_风险模型与收益归因.ipynb` | 协方差收缩/EWMA、因子暴露、行业/市值中性、VaR/ES、压力、回撤/杠杆、每日 PnL 归因 | 一张每日风险与归因表 |
| `05_实盘运维与逐笔对账.ipynb` | 事件 JSON/SQLite、内部/柜台对账、告警规则、kill switch、断线重连、事故 runbook、版本回滚 | 一套实盘运维清单 |
| `06_真实期权链与做市风险.ipynb` | 期权链清洗、买卖价 IV、Greeks、保证金、行权/指派、库存/做市风险 | 合成链上的做市与风险示例 |

## 怎么用

在 `tutorials/` 目录下启动 Jupyter：

```bash
cd tutorials
jupyter lab
```

然后打开 `advanced/` 下对应 notebook。代码使用相对路径，数据为合成/教学数据；不需要额外数据文件。

## 依赖

与主线相同：`numpy`、`pandas`、`scipy`、`matplotlib`。不需要 `statsmodels`。

## 说明

- 所有交易所参数、保证金率、乘数均为**教学示例**，不对应任何真实交易所；实盘前必须按 SHFE/DCE/CZCE/INE/GFEX 最新细则核对。
- `06` 使用合成期权链，不是真实市场数据；方法是可迁移的，数据要替换。
- 这些章节是“工程闭环”的起点，不是生产级交易系统；上线前仍需券商柜台、风控、监控、合规与资金审计。
