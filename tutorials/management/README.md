# Management：一人量化公司的经营与扩张

这套文档写给“一人 + AI + 期货/期权自营”的量化交易者，讨论**赚钱之后**的事：

- 商业模式怎么选：继续自营、做资管、卖技术，还是混合？
- 竞争靠什么：数据、执行、研究流程、成本，还是细分市场？
- 从一人到十人，组织怎么搭、人怎么招、钱怎么分？
- 日常运营、财务、合规、治理、规模化分别要做什么？

## 重要声明

- 本套文档是**经营知识整理，不构成法律、税务、投资、合规意见**。
- 具体监管要求、税率、数据许可条款会变化；执行前请咨询律师、税务师、券商、托管/审计机构，并以最新法规为准。
- 所有数字都是示例，不是收益承诺。
- 一人公司最大的风险不是“收益不够高”，而是**一次合规/风控/运营事故把多年积累清零**。
