# 09 规模化：资金、容量、产品化与退出

扩张不是“线性放大”。资金、容量、策略相关性、合规、人才，每一层都会卡住你。

## 一、三个阶段

| 阶段 | 自有/管理资金 | 重点 | 不要做 |
|---|---|---|---|
| 生存 | < 300 万 | 证明扣费后正期望、回撤可控 | 招人、接资金、扩品种 |
| 稳固 | 300–1000 万 | 2–3 个低相关策略、可审计记录、小团队 | 盲目加杠杆、做资管 |
| 扩张 | > 1000 万 | 容量/产品化/合规/人才 | 先收钱再补合规 |

## 二、容量

```text
容量 ≈ 市场日成交额 × 可接受参与率 × 策略持有期
```

扩张前要回答：

- 策略在多大资金下收益开始衰减？
- 冲击成本/滑点随规模怎么变？
- 多策略相关性如何？加资金是分散还是集中？
- 券商/交易所限制、保证金、涨跌停/持仓限额？

**不要用回测容量代替实盘容量。** 用小资金逐步加，记录滑点/成交率。

## 三、策略组合

- 目标：低相关、不同期限、不同品种、不同逻辑；
- 避免“十个策略其实是一个因子”；
- 定期做相关性/拥挤度/因子暴露检查；
- 单一策略占比上限；
- 策略衰减/停用规则。

## 四、产品化

如果做资管，常见结构：

- 专户/单独管理账户（SMA）；
- 私募基金/资管计划；
- 顾问/投顾模式（视资质）。

要准备：

- 产品合同/风险揭示/适当性；
- 托管/估值/审计；
- 费率/锁定期/赎回/侧袋/流动性；
- 投资者沟通/定期报告；
- 利益冲突/关联交易；
- 业绩展示合规。

**产品化是另一门生意**：渠道、服务、合规、运营，不是“策略好就有人买”。

## 五、人才与外包

| 职能 | 自建 | 外包 |
|---|---|---|
| 研究/交易 | 核心自建 | 不建议外包核心 |
| 开发 | 核心自建/部分外包 | 非核心可外包 |
| 风控 | 至少兼职/顾问 | 可外部审计 |
| 财务/税务 | 外包 | 常规 |
| 合规 | 顾问/律师 | 视业务 |
| 运营/对账 | 早期自建 | 可部分外包 |

## 六、退出选项

- 继续做家族办公室（不扩张，稳定现金流）；
- 卖给更大机构/战略投资者；
- 引入合伙人/股权融资；
- 技术授权/软件化；
- 有序关闭（保留本金/团队）。

**退出不是失败**；一人公司可以选择“小而美”，不必追求规模。

## 七、扩张决策门

在加资金/加人/做产品前，逐项打勾：

- [ ] 过去 24 个月扣费后正期望，回撤在限额内；
- [ ] 有可审计的对账/归因/事故记录；
- [ ] 策略容量测试过，滑点可接受；
- [ ] 有 12 个月现金储备；
- [ ] 合规/税务/数据许可已咨询；
- [ ] 关键人/灾备/权限有备份；
- [ ] 新增资金/人员不会让风险失控。

**任何一项打不了勾，先别扩张。**

## 八、一句话

> 扩张的目的不是“变大”，而是**在风险可控的前提下，让同样的 edge 装下更多资本**。  
> 如果 edge 本身不稳，扩张只会放大亏损。
