# 02 战略：定位与护城河

一人量化公司最怕的战略错误，是**什么都想做**：股票、期货、期权、高频、日内、CTA、套利、做市全上。资源分散后，每个方向都只有半桶水。

战略的本质是：**选一个能赢的细分市场，把资源压上去，形成别人难以复制的优势。**

## 一、先选战场：六个维度

| 维度 | 要回答的问题 | 一人公司的现实 |
|---|---|---|
| 市场 | 期货/期权/ETF/股票？ | 先 1–2 个品种/板块 |
| 频率 | 高频/日内/中频/隔夜？ | 避开拼速度的高频 |
| 容量 | 策略能装多少钱？ | 小资金反而有容量优势 |
| 竞争 | 谁在赚这个钱？ | 避开机构扎堆的拥挤交易 |
| 数据 | 我有什么别人没有的？ | 独特数据/清洗/执行细节 |
| 资本 | 我能承受多大回撤？ | 先活下来，再谈规模 |

### 一人公司更适合的战场

- 中低频、容量不大的细分策略；
- 期权相对价值、波动率、期限结构；
- 期货跨品种/跨期、展期、库存与基差；
- 机构因容量/合规/考核不愿做的“小而慢”机会；
- 需要大量工程/数据清洗、但不需要低延迟的领域。

### 一人公司不适合硬碰的战场

- 毫秒级高频、做市（拼基础设施和速度）；
- 需要庞大销售/渠道的资管产品；
- 需要牌照/资本金的重资产金融业务；
- 已经极度拥挤的“公开因子”交易。

## 二、护城河：一人公司能建什么

| 护城河 | 是否可建 | 说明 |
|---|---|---|
| 速度/低延迟 | 难 | 拼机房、FPGA、专线，资本密集 |
| 独家数据 | 中 | 数据授权贵，但清洗/拼接/另类数据可做 |
| 执行细节 | 可 | 下单算法、排队、滑点、券商关系 |
| 研究流程 | 可 | 假设→验证→组合→OOS 的纪律 |
| AI 工作流 | 可 | 快速试错、代码生成、文档/复现 |
| 成本结构 | 可 | 一人公司没有大机构的管理费 |
| 细分市场理解 | 可 | 品种季节性、交割、库存、产业细节 |
| 品牌/信任 | 慢 | 需要长期可审计业绩 |

**一人公司最现实的护城河：细分市场的深度理解 + 低成本 + 快速研究迭代。**  
不是“我的模型更聪明”，而是“我比别人更懂这个小市场，且成本更低”。

## 三、战略定位一句话

写不出来，就说明还没想清楚。模板：

> 我们专注【市场/品种】的【频率/持有期】的【策略类型】，  
> 为【自己/特定客户】提供【收益/风险/流动性】特征，  
> 靠【数据/执行/研究流程/成本】形成优势，  
> 不碰【明确不做的领域】。

示例：

> 专注国内商品期货的 1–10 天期限结构与展期策略，用产业库存/基差数据和低成本执行形成优势；不做高频、不做期权卖方、不接外部资金。

## 四、三层面战略

### 1. 生存层（0–12 个月）

- 目标：扣费后正期望、回撤可控、运营不断；
- 动作：1–2 个品种、1–2 个策略、严格风控；
- 不做什么：不扩品种、不招人、不接资金。

### 2. 稳固层（1–3 年）

- 目标：2–3 个低相关策略、可审计 track record；
- 动作：补数据/执行/风控，形成研究流水线；
- 开始考虑：主体、数据许可、小团队。

### 3. 扩张层（3 年以上）

- 目标：容量/资金/产品化；
- 动作：资管评估、技术授权、人才梯队；
- 关键：合规与治理先行，不要先收钱再补合规。

## 五、情景规划

不要只做“顺利版”计划，至少写三档：

| 情景 | 假设 | 应对 |
|---|---|---|
| 基准 | 年化 10–20%，回撤 15% | 按计划复利，控制成本 |
| 乐观 | 年化 25%+，容量足够 | 慢扩，先补风控/合规 |
| 悲观 | 连续 12 个月不赚钱 | 降杠杆、停策略、保留现金 |

**触发规则**：

- 回撤超过 X% → 降杠杆/停新开仓；
- 连续 N 个月跑输基准 → 策略评审；
- 运营事故 ≥ 2 次/季 → 暂停扩张，先修流程。

## 六、检查清单

- [ ] 我能否用一句话说清“做什么、不做什么”？
- [ ] 我选的战场，机构为什么不做/做不好？
- [ ] 我的护城河是“真的优势”，还是“自我感觉”？
- [ ] 我有没有明确的“不碰清单”？
- [ ] 我的三档情景和触发规则写下来了吗？

> 战略不是预测未来，而是**在不确定下决定把有限资源压在哪里**。
