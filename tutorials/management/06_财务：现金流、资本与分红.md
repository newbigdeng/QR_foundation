# 06 财务：现金流、资本与分红

量化交易者容易只看“收益率”，忽略“公司财务”。一人公司扩张时，现金流断裂比策略回撤更致命。

## 一、三本账

| 账本 | 记什么 | 用途 |
|---|---|---|
| 交易账 | 成交、持仓、手续费、滑点、PnL | 策略表现 |
| 公司账 | 收入、费用、税、工资、数据费 | 经营生存 |
| 资金账 | 自有资金、外部资金、出入金、分红 | 资本管理 |

**三本账必须能互相对上。**

## 二、收入与成本

```text
自营净收益 = 交易毛利 − 手续费/滑点 − 数据/软件/券商 − 人力 − 税
资管收入 = 管理费 + 业绩报酬
技术收入 = 授权/订阅/实施费
```

### 成本结构

| 类型 | 例子 | 特点 |
|---|---|---|
| 固定成本 | 数据、软件、工资、房租 | 不随收益下降 |
| 变动成本 | 手续费、滑点、云资源 | 随交易量 |
| 一次性 | 合规、审计、系统建设 | 扩张期集中 |

一人公司要特别警惕**固定成本吃掉了策略收益**：  
30 万本金，年固定成本 6 万，等于先要赚 20% 才保本。

## 三、现金储备

建议：

- 至少 **12 个月运营现金**；
- 交易资本与生活资金分离；
- 不把全部利润立刻分红/加杠杆；
- 黑天鹅/连续回撤时，有现金补保证金。

```text
安全垫 = 现金储备 / 月均运营成本 ≥ 12
```

## 四、利润分配

优先级建议：

1. 补足运营现金储备；
2. 补足交易资本/保证金缓冲；
3. 投入研究/数据/系统；
4. 股东分红；
5. 风险准备金。

**不要**：赚钱就全部提取、亏钱就借钱补保证金。

## 五、资本效率

| 指标 | 公式 | 意义 |
|---|---|---|
| ROE | 净收益 / 自有资本 | 资本回报 |
| 收益/风险 | 年化收益 / 最大回撤 | 生存能力 |
| 成本收入比 | 运营成本 / 收入 | 效率 |
| 现金覆盖月数 | 现金 / 月成本 | 安全垫 |
| 策略容量 | 可交易资金 / 当前资金 | 扩张空间 |

## 六、融资与杠杆

- **公司层面不要加杠杆**：交易杠杆已经够高，经营再借钱会放大破产风险；
- 优先用自有资金 + 留存利润；
- 外部资金（资管）是“负债式扩张”，要匹配合规/流动性；
- 股权融资只在需要大投入（数据/团队/牌照）时考虑，不要为交易本金融资。

## 七、预算模板（示例）

| 项目 | 年预算（示例） |
|---|---:|
| 数据/行情 | 1–5 万 |
| 券商/期货通道 | 按交易量 |
| 软件/云 | 0.5–3 万 |
| 会计/审计/合规 | 1–5 万 |
| 人力（如有） | 按人数 |
| 保险/杂费 | 0.5–2 万 |
| 现金储备 | ≥ 12 个月 |

数字仅示例，按自己情况填。

## 八、检查清单

- [ ] 我的交易账/公司账/资金账能对上吗？
- [ ] 我有多少个月现金储备？
- [ ] 我的固定成本占收益多少？
- [ ] 我是否在用短期资金做长期策略？
- [ ] 我的分红是否削弱了保证金缓冲？

> 财务的目标不是“省到极致”，而是**在任何市场环境下都能活到下一轮**。
