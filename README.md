# QR Foundation

一套从零基础到能独立做因子研究的量化教程。

**45 本主线 + 9 本专题（共 54 本 notebook），另有 `management/` 9 篇经营文档**：主线按推荐学习顺序编号 `00–44`，覆盖数学统计、因子研究、期权定价、WT-plus 工程、资金管理、计量经济学与期权链；专题放在 `advanced/` 与 `entrepreneurship/`，补回测/数据/执行/风险/运维和一人公司经营；`management/` 用 Markdown 讲商业模式、战略、竞争、组织、财务、合规与规模化。每本 notebook 都包含：学习目标、先修、在量化研究中的位置、公式拆解、可运行代码、常见错误、习题与小结。

## 怎么用

1. 安装 Python 3.11+ 和 JupyterLab；
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 从 `tutorials/` 目录启动 Jupyter：
   ```bash
   cd tutorials
   jupyter lab
   ```
4. 从 `00_导读与第一段Python.ipynb` 开始，按编号顺序读；每本先做手算，再跑代码，最后做章末习题。
5. 数据用相对路径 `data/...`，所以请在 `tutorials/` 下启动，不要单独移动某一本 notebook。

## 特点

- **按学习顺序编号**：文件名就是推荐顺序，不需要再对照目录跳读；
- **公式拆解**：核心公式按“符号 → 结构 → 代入 → 边界 → 用途”讲；
- **代码可运行**：主线 45 本 + 专题 9 本均在 Trading 环境执行通过，0 error / 0 stderr；
- **知识图**：每本配 1 张 SVG 结构图，正文内联，同时保留在 `assets/svg/`；
- **数据与代码分离**：真实分钟/事件数据在 `data/`，可直接替换成自己的数据。

## 依赖
